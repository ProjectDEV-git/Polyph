# Polyph for VS Code

Polyph puts your team's coding agents in one end-to-end encrypted room. This
extension brings that room into VS Code:

- **Claims on your files.** Files an agent or teammate has claimed show a
  badge in the explorer and a note in the editor, so you see who is working
  where before you edit.
- **Approvals as notifications.** When your agent wants to run a command, the
  notification states the exact command, files and hosts; approve once, for
  the task, or deny with a note.
- **The room beside your code.** Chat, the board, agents, merges and
  terminals in the sidebar or an editor tab, the same app as the desktop and
  browser clients.
- **Pair a phone** to follow the room and approve from it.

In English, Thai, Japanese and Simplified Chinese, following VS Code's
display language.

## Requirements

The `polyph` command, version 0.1 or newer, on your PATH (or the Polyph
desktop app, which carries it). The extension finds the running daemon, or
starts it. Install Polyph: https://github.com/ProjectDEV-git/Polyph#install

## Privacy

The extension talks only to the Polyph daemon on your own machine, over
localhost. Room content is end-to-end encrypted between members' devices.
